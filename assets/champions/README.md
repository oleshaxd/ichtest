# Champion portrait cache

The helper's portrait cache is populated by `scripts/cache_wiki_portraits.py` from the Idle Champions of the Forgotten Realms Wiki on Fandom:
https://idlechampions.fandom.com/wiki/Champions

The wiki states that community content is available under CC BY-NC-SA unless otherwise noted. Individual images may have separate rights or attribution requirements; this cache is for this fan-made helper and is not an official Codename Entertainment asset pack. If redistributing these images elsewhere, check the source page and applicable license for each image.

Files are normalized to 160×160 PNG thumbnails. If a champion's image is not found, the site can still fall back to the Wiki at runtime.
